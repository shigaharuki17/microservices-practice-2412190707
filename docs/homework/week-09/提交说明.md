# 第九周大作业提交文字与截图对应

GitHub 仓库：https://github.com/shigaharuki17/microservices-practice-2412190707

## 1. API Gateway

已在原社区报修项目中新增独立网关，使用服务名发现住户、维修人员和报修三个服务，统一通过 18081 端口访问。原 Ubuntu 部署中三条业务路由均返回真实 JSON 和 200，健康端点返回 UP。截图上传 `01-ubuntu-gateway.png`，可补充 `05-ubuntu-code.png`。

## 2. 认证服务

已在住户服务实现数据库账号登录，密码使用带随机盐的 BCrypt 哈希存储，校验通过后签发有效期 30 分钟的 JWT。区分 ADMIN 与 RESIDENT 角色，错误密码、篡改令牌和过期令牌均被拒绝。测试账号为 admin 和 resident，随机密码仅保存于本地环境文件。截图上传 `02-ubuntu-authentication.png`，可补充 `05-ubuntu-code.png`。

## 3. 网关鉴权

已验证未登录返回 401，普通账号调用管理接口返回 403，管理员访问同一路径返回 200。网关覆盖客户端伪造的身份头，下游接口校验内部凭据，诊断端口仅绑定回环地址，直连后端伪造身份也无法访问。截图上传 `03-ubuntu-authorization.png`。

## 4. 测试脚本

在仓库根目录运行 bash scripts/auth-test.sh，可重复验证未登录、两类账号登录、三条路由、角色越权、身份伪造、令牌篡改与过期、后端直连以及 Feign 内部协作。本轮 Ubuntu 实际 HTTP 检查 17 项全部通过，本机服务测试共 45 项通过，失败返回非零退出码。截图上传 `04-ubuntu-tests.png`。

以上证据已更新为原 Ubuntu 部署实测。更新前已备份，原有 11 条住户、15 条维修人员和 21 条工单的数据快照及原数据卷均保持一致。完整配置、源代码、测试和限制说明见本周 index.md 与 docs/security.md。
