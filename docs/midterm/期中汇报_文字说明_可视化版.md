# 期中汇报文字说明

## 1. 项目名称和主要用途

我的课程项目是“社区报修与上门维修服务平台”，可视化工作台命名为“邻里修”。项目面向住户、物业管理员和维修人员，用于集中记录报修需求，支持审核、派单、接单及进度查询，减少报修信息分散和处理状态难追踪的问题。

## 2. 当前已经完成的功能与技术工作

目前已完成基础可视化工作台，支持住户和维修人员档案新增、工单统计、搜索筛选、分页与详情查看，并可直接通过页面完成报修提交、审核通过或驳回、按技能派单及确认接单。此次实际页面演示创建工单 BX-0011，依次经过 SUBMITTED、APPROVED、ASSIGNED，最终进入 ACCEPTED，相关页面截图已放入汇报 PPT。

技术上使用 Spring Boot、Web MVC、Spring Data JPA 和 MySQL，保留原单体，并拆分为住户、维修人员和报修三个独立服务，各自拥有独立数据库。已完成 Docker 多阶段构建、Compose 编排、数据卷持久化、Actuator 健康检查及 Nacos 服务注册与发现。跨服务通过发现的实例地址发送 HTTP 请求，不跨库访问。报修服务当前 19 项自动化测试通过；独立页面故障验证中，依赖服务下线时显示 HTTP 503，工单数保持 9 条，恢复后新请求成功创建工单 10。

## 3. 目前的问题、尚未完成的内容及后续计划

目前服务上下线的发现状态传播需要等待，远程校验与本地事务提交之间仍存在时间窗口。页面尚未实现业务用户登录、角色授权和数据范围限制，现阶段为课程演示模式，确认接单也不代表维修完工。维修完工、住户验收、预约、报价、材料库存、支付及生产级高可用部署尚未实现。

后续先补登录认证、角色权限和数据范围限制，再完善维修完工、住户验收及进度通知，随后补充日志与监控，并逐步研究幂等和跨服务一致性处理。
